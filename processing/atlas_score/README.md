# Imagination Score · 黑白 Processing 草图 v0.1

Experiment 01 的三维想象谱。草图读取 `data/scores.json`，**所有空间位置都由下面的规则自动计算**，没有手工摆放。新增作品时只需往 JSON 里添加数据。

运行方法：用 Processing 4 打开 `atlas_score.pde`，点 Run。不需要任何外部库。

## 数据结构（每件作品）

| 字段 | 内容 |
|---|---|
| `referents` | R：`absence`（缺席方式）、`kind`（对象种类）、`parent`（嵌套）、`embodied`（在图中有形体）、`viewer`（面向观者）、`inferred`（仅推断） |
| `carriers` | C：可见载体；`count` 表示多个同类，`shape: disk` 表示平面载体 |
| `ops` | O：`type`、`from`、`to`、`evidence`（text / image / inference）、`quote`（证据原文） |

## 布局规则

1. 载体放在地面上（可见世界），沿 x 轴排开。
2. 用于"纵深 = 时间"的载体被推到后方（-z），越往后越是未来。
3. `layer(from, to)`：from 叠放在 to 的正上方。
4. **高度 = 链的深度**。由另一个 R 指向的 R 高一层（例：母爱 → 慈爱）。
5. 缺席方式为"未至"的 R 被推向后方。
6. 只能被"见证"的 R 放在画框之外，靠观者一侧，同时画出画框。
7. 面向观者的 R 放在最高处，并偏离场景。
8. 有 `parent` 的 R 放在容器内部，属于未来的偏后。

## 黑白视觉语法

| 元素 | 画法 |
|---|---|
| 可见载体 | 实心方块 |
| 在图中有形体的 R | 灰色实体 |
| 不在场的 R | 只画线框：球 = 存在者，大球 = 经验（容器），锥 = 事件，八面体 = 概念，稀疏球 = 世界 |
| 文本证据 | 实线 |
| 仅图像证据 | 淡虚线（按 G 显示或隐藏） |
| 推断 | 极淡（按 I 显示，默认隐藏，不计入签名） |

## 操作符号

| 操作 | 符号 |
|---|---|
| 外化 / 拟人化 | 从载体张开的漏斗 |
| 铭写 | 直线加刻线，像乐谱的歌词行 |
| 象征替代 | 直线、双环（=）、箭头 |
| 提喻 | 沿线逐渐变大的圆环 |
| 纵深 = 时间 | 虚线，圆环间距向未来方向拉大 |
| 时代错置 | 缠绕主线的螺旋 |
| 并置 | 两个载体之间的点状拱线 |
| 见证 | 多条汇聚的虚线视线 |
| 不可能视点 | 天球外的观者点，加上视线扇面和投影线 |
| 仪式激活 | 虚线上不断向上移动的圆环 |
| 分层 | 竖线加隔板 |
| 中心辐射 | 平面上的放射线 |
| 重复 | 等距排列的载体连线 |
| 赋形 | 天球表面的小实体 |

## 按键

`← →` 或 `1–5` 切换作品 · `L` 标签 · `T` 中文 / English · `G` 图像证据 · `I` 推断 · `B` 黑白反转 · `SPACE` 自动旋转 · `R` 复位视角 · `S` 保存 PNG 到 `export/`
